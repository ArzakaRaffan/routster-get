FAQ

Pertanyaan umum

Apa bedanya dengan Hermes Agent?

Routster Agent adalah fork dari Hermes Agent (MIT). Bedanya: Routster jadi provider default dan datanya di ~/.routster, jadi bisa dipasang bareng Hermes.

Harus punya akun Routster?

Ya, daftar di routster.trackster.dev. Key provider lain juga bisa: routster auth add <provider>.

Aman dipakai di repo saya?

Perintah berisiko minta izin dulu. Untuk isolasi, pilih sandbox lewat routster setup terminal.

Bisa di Windows?

Bisa, lewat PowerShell:

irm https://get.routster.trackster.dev/install.ps1 | iex
Cara update?

Jalankan routster update.

Mau instal manual dari source?
git clone https://github.com/ArzakaRaffan/routster-agent.git
cd routster-agent
uv python install 3.14
"$(uv python find 3.14)" -m pm.build_env --source . --out ~/.local/share/routster-agent/venv
mkdir -p ~/.local/bin && ln -sf ~/.local/share/routster-agent/venv/bin/routster ~/.local/bin/routster
