FAQ

Pertanyaan umum

Apakah ini open source?

Ya, lisensi MIT. Routster jadi provider default dan semua datanya di ~/.routster, jadi aman jalan berdampingan dengan tool lain.

Harus punya akun Routster?

Untuk model Routster, ya: daftar dan top up QRIS di routster.trackster.dev. Provider lain cukup pakai key-nya sendiri.

Bisa pakai 9router atau model lokal?

Bisa. Jalankan routster model, pilih Custom endpoint, lalu masukkan URL OpenAI-compatible apa pun (untuk 9router: http://localhost:20128/v1).

Aman dipakai di repo saya?

Perintah berisiko menunggu izin kamu (--yolo mematikannya). Untuk isolasi, pilih sandbox lewat routster setup terminal.

Bisa di Windows?

Bisa, lewat PowerShell. Di WSL, pakai perintah curl.

irm https://get.routster.trackster.dev/install.ps1 | iex
Cara update?

Jalankan routster update.
